# BARA 1946

Gunakan Bahasa Indonesia untuk penjelasan. Jangan gunakan bold atau italic.

Repository ini menggunakan Luau dan Script Sync bawaan Roblox Studio.
Kerjakan source code dari direktori repository ini. Roblox Studio MCP harus
diarahkan pada sesi yang benar sebelum membaca atau mengubah instance.

- Roblox Studio mengelola map, model, environment, dan playtest.
- VS Code dan Codex mengedit source code dalam src setelah Script Sync diverifikasi.
- Jangan jalankan Rojo atau sinkronisasi lain pada folder Script Sync.
- Jangan timpa konflik otomatis. Baca perbedaan Studio dan disk terlebih dahulu.
- Script Sync hanya mengelola Script, LocalScript, ModuleScript, dan Folder.
- Jangan menambahkan attribute atau tag yang harus dipertahankan ke script synced.
- Jangan menghapus map, model, atau script yang sudah ada tanpa instruksi pengguna.
- Jangan commit credential atau file place. Cadangkan place secara terpisah.
- Pengguna mengizinkan commit dan push otomatis setiap progres yang selesai dan
  sudah diperiksa, tanpa meminta konfirmasi ulang. Stage hanya file tugas terkait.
- Gunakan akun GitHub pengguna Constanvel dan remote origin repository ini pada
  branch main. Pertahankan identitas Git pengguna; jangan gunakan identitas agen.
- Verifikasi akun aktif sebelum push. Jika akun berbeda, login kedaluwarsa, atau
  ada konflik remote, hentikan push dan laporkan. Jangan force push atau menimpa
  perubahan pengguna. Cocokkan SHA lokal dan remote setelah push.
- Setup awal belum boleh dianggap VERIFIED sampai tes sinkronisasi dua arah lulus.

Lihat docs/SETUP_STATUS.md untuk checkpoint dan docs/SCRIPT_SYNC.md untuk pemetaan.
